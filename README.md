# 🎮 Memory Match Game
A fun and interactive **Memory Match Game** built using HTML, CSS, and JavaScript. The game challenges players to find matching pairs of emoji cards while testing their memory and concentration.
## ✨ Features
- 🃏 **Interactive Cards:** Flip cards to reveal emojis and find matching pairs.
- 🔀 **Randomized Cards:** Cards are shuffled for a fresh gaming experience.
- ⏱️ **Timer:** Tracks the time taken to complete the game.
- 🔢 **Move Counter:** Keeps track of the number of moves made.
- 🧠 **Memory Challenge:** Improves concentration and memory skills.
- 🔄 **Restart Game:** Restart and play again.

## 🛠️ Technologies Used
- **HTML5** – Structures the game interface.
- **CSS3** – Styles the cards, layout, and overall design.
- **JavaScript** – Implements game logic, card matching, event handling, timer functionality, and DOM manipulation.

## 🎯 How to Play
1. Open the game in your browser.
2. Click on any card to reveal an emoji.
3. Click another card to find its matching pair.
4. Match all the pairs to complete the game.
5. Try to finish in the least amount of time and with fewer moves!
